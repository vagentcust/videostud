# REELY — Creator Edition

Видеоредактор в браузере и Telegram-бот [@videouibot](https://t.me/videouibot). Node.js 22+, без npm-зависимостей.

## Возможности

- Собственный графитово-мятный дизайн, адаптивная компоновка, анимации кнопок и режим reduced motion.
- До 10 видео по 200 МБ, перестановка и обрезка каждого фрагмента.
- Форматы 9:16, 1:1, 16:9, 4:5; заполнение кадра или сохранение всего изображения.
- Скорость 0.5–2×, громкость, яркость; четыре стиля текста.
- Постоянная подпись или импорт SRT с таймкодами итогового ролика; размер и положение текста.
- Экспорт последовательности видео с аудио через Canvas + MediaRecorder в WebM (MP4 при поддержке браузером). Экспорт идёт в реальном времени; вкладку нужно держать открытой.
- Кадр PNG, импорт/экспорт настроек JSON.
- Проекты с исходниками в IndexedDB, поиск, сортировка, избранное, копирование, восстанавливаемый архив.
- Ctrl+S — сохранение; Space — воспроизведение вне полей ввода.

Автораспознавание речи, автоматическое удаление пауз, платежи и облачная синхронизация не подключены. JSON не содержит исходные видео. Очистка данных браузера удаляет проекты. Localhost и GitHub Pages имеют отдельные хранилища.

## Локальный запуск

```powershell
npm start
```

Сайт: http://127.0.0.1:4173. В Windows `./start-local.ps1` запускает сайт и бота в фоне; PID и логи находятся в игнорируемой папке data. После перезагрузки компьютера выполните скрипт снова.

## Настройка бота

Скопируйте `.env.example` в `.env`. Заполните BOT_TOKEN и WEBAPP_URL. Токен хранится только локально, никогда не в public/ или GitHub.

```powershell
npm run bot
```

Для опубликованного сайта: `WEBAPP_URL=https://vagentcust.github.io/videostud/`.

Подписка проверяется на `@testvideoui`, бот должен быть администратором. `REQUIRE_SUBSCRIPTION=true` включает обязательную проверку перед каждым сообщением и callback. Кнопки «Подписаться» и «Проверить подписку» адаптированы из кода V-Agent-Telegram-Bot пользователя (см. SOURCE-NOTES.md). При ошибке Telegram доступ не выдаётся. Прямой публичный сайт не закрыт этой проверкой: это проверка навигации в боте, а не серверная авторизация платных операций.

Премиум-эмодзи проверены через getCustomEmojiStickers; источники в emoji-sources.json. Их ID задаются в `.env`. При отказе Telegram используется обычное меню. Для `/emoji` задайте BOT_OWNER_ID.

## GitHub

Репозиторий: https://github.com/vagentcust/videostud

Workflow checks.yml запускает тесты. pages.yml публикует только public/, без токенов и кода бота. В Settings → Pages должен быть выбран GitHub Actions. GitHub Pages раздаёт сайт; процесс Telegram-бота продолжает работать на компьютере или отдельном сервере, а не в GitHub Actions.

```powershell
npm test
node --check public/app.js
node --check public/render.js
node --check bot.mjs
```

Проверены 10 тестов: статусы подписки и отказ при ошибке, emoji fallback, SRT, обрезка, скорость и валидация импорта. В браузере проверены загрузка CC0-ролика MDN, сохранение проекта и фактическое скачивание WebM. Для сторонних кодеков поведение зависит от браузера.
